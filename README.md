# CareSync

CareSync is a trustworthy AI-powered care coordination platform designed for aging parents, family caregivers, and verified volunteers.

## Directory Structure

- `frontend/` - React + TypeScript + Vite + Tailwind CSS design system and application.
- `backend/` - FastAPI modular monolith backend service and Strands Agent integration.
- `docs/` - System architecture, domain models, OOAD, and security specifications.
- `tests/` - End-to-end and scenario test suites.

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173/design-system` to inspect the CareSync Design System showcase.
